Document Structure

STRUCTURE
 HTML Boilerplate 
<!-- Every HTML document starts with this -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>Welcome to HTML.</p>
  </body>
</html>
Output
Browser Tab: My Page

Hello World!

Welcome to HTML.

Global Attributes

ATTRIBUTES
 Common HTML Attributes 
<!-- id: unique identifier -->
<div id="main-header">Header</div>

<!-- class: group multiple elements -->
<p class="highlight big">Text</p>

<!-- style: inline CSS -->
<h1 style="color: blue;">Title</h1>

<!-- title: tooltip on hover -->
<abbr title="HyperText Markup Language">HTML</abbr>

<!-- data-*: custom data attributes -->
<div data-user-id="42">User</div>

<!-- hidden: hides element -->
<p hidden>Not visible</p>

<!-- tabindex: keyboard nav order -->
<button tabindex="1">First</button>
<button tabindex="2">Second</button>

<!-- contenteditable -->
<p contenteditable="true">Click to edit</p>

<!-- draggable -->
<div draggable="true">Drag me</div>
AttributePurpose
idUnique identifier; used for CSS, JS, anchor links
classGroups elements; multiple classes space-separated
styleInline CSS styles (avoid for large projects)
titleTooltip shown on hover
data-*Custom data stored on element, accessible via JS
hiddenBoolean — hides element from display
tabindexControls keyboard focus/tab order
contenteditableMakes element's content editable by user
draggableEnables HTML5 drag & drop API
langDeclares language (e.g. lang="en")
dirText direction: ltr or rtl

Generic Containers

CONTAINERS
 <div> vs <span> 
<!-- div: block-level container -->
<div style="background:#f0f0ff; padding:1rem;">
  <h3>Card Title</h3>
  <p>Card content goes here.</p>
</div>

<!-- span: inline container -->
<p>
  This is <span style="color:red">red text</span>
  inside a paragraph.
</p>

<!-- Nesting divs for layout -->
<div class="container">
  <div class="col">Column 1</div>
  <div class="col">Column 2</div>
</div>

11

Head & Meta Tags

HEAD
 <meta>, <link>, <script> 
<head>
  <!-- Character encoding -->
  <meta charset="UTF-8">

  <!-- Responsive viewport -->
  <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

  <!-- SEO: page description -->
  <meta name="description"
    content="Learn HTML basics">

  <!-- SEO: keywords -->
  <meta name="keywords"
    content="HTML, web, tutorial">

  <!-- Author -->
  <meta name="author" content="Dev">

  <!-- Open Graph (social sharing) -->
  <meta property="og:title"
    content="My Page">
  <meta property="og:image"
    content="thumbnail.jpg">

  <!-- External CSS -->
  <link rel="stylesheet" href="style.css">

  <!-- Favicon -->
  <link rel="icon" href="favicon.ico">

  <!-- Google Fonts -->
  <link rel="preconnect"
    href="https://fonts.googleapis.com">

  <!-- JavaScript file -->
  <script src="app.js" defer></script>
</head>
Tag / AttributePurpose
charset="UTF-8"Sets character encoding for international text
viewportMakes page responsive on mobile devices
name="description"SEO — shown in Google search results
name="keywords"SEO keywords (less important now)
og:title / og:imageControls preview when sharing on social media
link rel="stylesheet"Links an external CSS file
link rel="icon"Sets the browser tab favicon
script deferLoads JS after HTML is parsed
